# GASTROIFF

Plataforma experimental da Gastronomia do IFF campus Cabo Frio - RJ.

Este projeto é uma iniciativa de organização pedagógica, de pesquisa, extensão e acervo. Não substitui o portal institucional do campus Cabo Frio - RJ.

A publicação apresenta dados acadêmicos confirmados até 31 de outubro de 2026. A lista de docentes foi encaminhada pela coordenação. Algumas informações, fotografias e links estão em verificação.

Site: https://gustavoguterman-gif.github.io/gastroiff/
